# SZABIST Student LMS

A full **Learning Management System (LMS)** interface designed for my university, SZABIST, as a semester project. The goal wasn't just to fulfill an assignment brief — it was to design something students would genuinely want to open and use every day, rather than another clunky academic portal.

🎨 **Design:** [View on Figma](https://www.figma.com/design/CVruA45mTKAV1MM9X0K6KP/SZABIST-Project)

## The Focus

Rather than treating this as a purely academic exercise, I approached it with a product mindset — thinking through real student workflows like checking assignments, tracking grades, viewing schedules, and accessing course materials, then designing an interface that makes those everyday tasks simple and intuitive.

## Status

🔄 **In Progress** — Currently converting this design from Figma into a real, functional LMS project, moving from static UI/UX mockups into an actual working application.
